# 생성 체크리스트

PeroPix 3.7.12의 캐릭터 순차 생성에서 마음에 드는 인물·씬 조합을 체크하고, 남은 조합만 다시 생성하는 플러그인입니다.

## 사용

인페인트 등 후편집을 시작할 때 생성 화면 하단 또는 체크리스트 창에서 **체크리스트 ON**을 눌러 **OFF**로 바꾸세요. 모든 작업 탭에서 PeroPix의 기본 요청과 정렬을 사용하고, 체크·대표·동반 선택은 보관합니다. 같은 버튼을 다시 누르면 기존 설정으로 돌아옵니다. 이미 대기열에 들어간 요청은 제출 당시 설정을 따릅니다. PeroPix를 완전히 재시작하면 ON으로 시작합니다.

1. 압축을 풀어 `PeroPix/plugins/seq-checklist/plugin.json`이 되도록 놓고 PeroPix를 다시 실행합니다.
2. 작업 탭에서 캐릭터 순차 생성을 켭니다. 기존 **생성** 버튼으로 첫 묶음을 생성합니다.
3. 생성 화면 하단의 **생성 체크리스트**를 누르면 같은 화면 위에 작은 창이 열립니다. 제목줄을 끌어 옮기거나 **접기**로 줄일 수 있습니다. 플러그인 탭에서는 기존 큰 화면도 열 수 있습니다. 행은 켜진 캐릭터, 열은 현재 그룹의 잠금이 풀린 씬입니다. 마음에 드는 결과가 나온 칸을 체크합니다. 체크를 풀면 다음 생성에 다시 포함됩니다.
4. 같은 조합에 여러 결과가 있다면 칸의 **대표**에서 원하는 썸네일을 골라 고정합니다. 대표를 고정하면 해당 조합도 체크됩니다.
5. 기존 **생성** 버튼을 누르면 빈칸만 큐에 들어갑니다. 한 바퀴에 인물 3명과 씬 3개 중 5칸이 체크되면 요청은 4장입니다. 한 슬롯당 2장이면 8장입니다. 이미 대기열에 들어간 요청은 제출 당시의 선택을 따릅니다.

## 씬의 이미지 순서

**대표 이미지 자동 지정**을 누르면 현재 그룹의 잠금이 풀린 씬에서 켜진 주인공별로 가장 최근의 식별 가능한 이미지를 대표로 고정하고 체크합니다. 기존에 고정한 대표는 우선합니다. 씬에서 대표가 빈 인물이 한 명이거나 체크하지 않은 인물이 한 명만 남았다면, 그 인물에게 아직 배정되지 않은 최신 미분류 이미지 한 장을 사용합니다.

대표 파일을 삭제하면 다음 체크리스트 갱신이나 생성 요청 시 해당 조합의 체크가 풀립니다. PeroPix에서 Ctrl+Z로 파일을 복원하면 기존 대표와 체크도 돌아옵니다. 그사이 다른 대표를 골랐다면 새 선택을 따릅니다. 파일 없이 직접 체크한 칸은 그대로 유지됩니다.

생성 탭 하단의 **체크리스트 새 창** 또는 체크리스트 안의 **새 창으로 분리**를 누르면 생성 화면을 유지한 채 별도의 Windows 창을 열 수 있습니다. 창 제목줄을 끌어 다른 모니터로 옮길 수 있습니다. 다시 누르면 기존 창이 앞으로 옵니다. 본창 내부에서만 사용할 때는 **생성 체크리스트**를 누릅니다.

업데이트 직후 동반을 선택할 때 재시작 안내가 뜨면 작업을 저장하고 PeroPix를 완전히 종료한 뒤 다시 실행하세요. 앱이 시작할 때 저장 기능을 불러옵니다.

생성 화면 또는 소형 창에서 **인물별 정렬**을 누르면 순차 생성이 꺼져 있어도 현재 씬 그룹을 인물순으로 다시 표시합니다. 후편집 결과는 이미지의 생성 정보로 식별하고, 부족하면 같은 씬 그룹의 원본 연결을 따라갑니다. 연결이 없는 파일도 **대표**에서 직접 지정할 수 있습니다.

순차 생성 탭의 각 씬에서 캐릭터 순서대로 대표 이미지가 먼저 보입니다. 사용자가 고정한 이미지가 우선이고, 자동 선택은 해당 캐릭터로 식별된 가장 최근 이미지를 사용합니다. 같은 캐릭터의 다른 결과도 뒤에서 볼 수 있습니다. 원본 이미지와 생성 시각은 보존합니다.

캐릭터는 PNG의 NAI 생성 정보와 WebP·JPEG의 EXIF 등으로 식별합니다. 이 플러그인으로 생성한 이미지에는 PeroPix의 작업 기록에도 캐릭터 ID가 남아, 메타데이터가 있는 파일의 식별을 돕습니다. 식별할 수 없는 이미지끼리는 생성 순서를 따릅니다. 메타데이터가 없는 씬에서 대표 파일을 직접 지정하면 그 위치를 우선합니다. 자동 정렬과 대표 지정은 저장된 이미지에 적용됩니다.

체크와 대표 지정은 워크스페이스 이름 및 씬 그룹별로 플러그인의 `_data/checklist.sqlite3`에 보관합니다. 인물·씬은 내부 ID로 구분합니다. 워크스페이스 폴더의 이름을 바꾸면 다른 체크리스트로 열립니다.

## 동반 캐릭터

**동반 캐릭터 선택**을 펼쳐 함께 생성할 인물을 체크합니다. 한 명을 체크하면 매 씬에서 주인공은 캐릭터 1, 동반 인물은 캐릭터 2로 들어갑니다. 다른 주인공을 켜면 그 주인공도 같은 동반과 한 장씩 생성됩니다. 씬의 `#1`, `#2` 지시도 이 순서를 따릅니다.

그룹명의 **전체**를 체크하면 그 시점의 그룹 멤버 전원이 한 번에 추가됩니다. 탭에서 꺼 둔 멤버도 동반으로 선택할 수 있습니다. 여러 동반은 탭의 캐릭터 순서로 2번부터 배치됩니다. 해제는 개별·그룹 모두 가능합니다. 씬 그룹마다 선택을 저장하며, 켜진 주인공은 한 명 이상 있어야 합니다. 현재 모델의 한도를 초과하면 전송 전에 안내합니다.

## 생성 비용 표시

PeroPix 기본 생성 버튼의 사전 장수·비용 표시와 일부 대기 썸네일은 제외 전 전체 조합을 기준으로 보일 수 있습니다. 체크리스트에서 한 바퀴에 남은 조합 수를 볼 수 있고, 제외가 적용된 요청을 넣으면 알림에 실제 제출 장수가 표시됩니다. 체크가 모두 차면 생성 요청을 보내지 않습니다.

기본 생성 버튼 연동과 씬 내부 정렬은 PeroPix 3.7.12의 웹 화면 구현에 맞춰져 있습니다. 본체 업데이트 후에는 적용 여부를 다시 확인하세요.
